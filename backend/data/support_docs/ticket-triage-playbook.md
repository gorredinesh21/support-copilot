# Ticket triage
## Steps
1. Classify severity per the escalation policy (see support-escalation-policy).
2. Extract identifiers early: tenant ID, subscription, request/correlation ID, operation_Id.
3. Search the knowledge base; if an article answers it, link the article and resolve.
4. If two engineers see the same issue within 60 minutes, raise severity one level and inform the service owner.
## Quality bar
Every resolved ticket records: root cause, fix or workaround, and the doc that helped (or 'no doc' — which feeds back into KB gaps).
