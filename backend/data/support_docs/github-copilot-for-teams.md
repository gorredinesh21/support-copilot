# Copilot in daily engineering
## Where it helps
Boilerplate, tests from examples, doc comments, learning an unfamiliar codebase by asking for walkthroughs.
## Where to verify
Security-sensitive code, license compliance, concurrency logic. Copilot suggestions are not reviewed code until a human reviews them.
## Policy
- Never paste customer data or secrets into prompts.
- Prefer workspace-aware Copilot Chat with @workspace for repo-specific answers.
- CI stays the quality gate: Copilot does not bypass tests or reviews.
